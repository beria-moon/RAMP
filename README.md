# Dance–Music User Study

Anonymous static questionnaire for GitHub Pages.

## Deploy

1. Create an empty GitHub repository.
2. Commit and push all files in this directory to the `main` branch.
3. In repository settings, enable Pages from `main` / root.
4. Open `https://<username>.github.io/<repository>/`.

Do not copy `../github_pages_method_key.private.json` into this repository.
Participant progress remains in the browser. Completed ratings are exported as CSV.
